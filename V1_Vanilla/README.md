## 🚀 How to Run Locally

You can preview the website immediately using Python's built-in HTTP server:

```bash
# In the resume-portfolio directory:
python3 -m http.server 3000
```
Open your browser and navigate to `http://localhost:3000`.

Alternatively, simply open `index.html` directly in any modern web browser (Chrome, Firefox, Edge, Safari).

---

## 🌐 Deploy to GitHub Pages (Free & Instant)

1. Push this repository to your GitHub account (`github.com/skmdaarif/portfolio` or `github.com/skmdaarif/skmdaarif.github.io`).
2. Navigate to **Settings** > **Pages**.
3. Under **Source**, select `Deploy from a branch` and choose `main` / `root`.
4. Click **Save**. Your portfolio will be live at `https://skmdaarif.github.io`!
